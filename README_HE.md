# מערכת אוטומציה למבא״ת

יישום Windows משולב Electron + React + Python לניהול פרופילי כניסה, טעינת רשומות מ-Excel/CSV/Word והרצת תהליך דפדפן לפי רשימת שלבים ניתנת לעריכה. ממשק React מבוסס על מאגר `ticnutai/tanenbaum-architects-portal` ומחובר למנוע Python המקומי.

## אבטחת סיסמאות

- הסיסמה אינה נשמרת בקוד, ב-Excel או ב-`workflow.json`.
- כאשר מסמנים שמירה מאובטחת, הסיסמה נשמרת דרך Windows Credential Manager.
- קוד חד-פעמי, ביומטריה ו-CAPTCHA נשארים פעולות ידניות.
- ברירת המחדל היא "מצב בדיקה": המערכת מציגה מה הייתה מבצעת בלי לפתוח דפדפן ובלי לשלוח נתונים.

שלב מסוג `fill_secret` מציג בעמודת הסיסמה 🔑 כאשר חסרה סיסמה ו-🔒 כאשר היא שמורה. לחיצה כפולה על השלב, או לחיצה על **🔑 ניהול סיסמה**, מאפשרת ליצור פרופיל, להחליף סיסמה או למחוק אותה. כל שלב יכול להיות מקושר לפרופיל סיסמה אחר.

## התקנה ראשונית

פתח PowerShell בתיקייה זו והרץ:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

לחלופין ניתן להפעיל פעם אחת את `setup_app.bat`.

## הפעלה

```powershell
.\.venv\Scripts\Activate.ps1
python app.py
```

לאחר ההתקנה אפשר להפעיל בלחיצה כפולה על `run_app.bat`. הוא מעלה את מנוע Python, שרת React המקומי וחלון Electron אחד. `run_web.bat` פותח את אותה מערכת בדפדפן, ו-`run_classic.bat` פותח את ממשק Windows הישן כגיבוי.

ממשק React זמין רק במחשב המקומי בכתובת `http://127.0.0.1:18474`. מנוע ה-API של Python מאזין ב-`http://127.0.0.1:18473`. המערכת כוללת סיידבר מלא, רשימת שלבים בכרטיסים, גרירה, בחירה מרובה, ניהול סיסמאות, טעינת נתונים, הפעלה במצב בדיקה או בדפדפן, הקלטת פעולות, יומן ריצה, דוח שגיאות וקונסול עם העתקה.

## סדר עבודה

1. בכרטיסייה **פרופילי כניסה** צור פרופיל והזן סיסמה בשדה המוסתר.
2. בכרטיסייה **הפעלה** הזן את חשבון Google הרצוי ולחץ **התחל – פתח Chrome**. בפעם הראשונה התחבר לחשבון בתוך פרופיל Chrome של המערכת; החיבור יישמר להפעלות הבאות. אפשר גם להשתמש בכפתור **בדיקת Chrome בלבד**.
3. הכפתור פותח ישירות את כתובת סימניית מבא״ת. ניווט ישיר יציב יותר מלחיצה לפי מיקום האייקון בסרגל ומוביל לאותו דף.
4. בכרטיסייה **נתוני לקוחות** בחר Excel, CSV או Word. ב-Word הנתונים צריכים להיות בטבלה; ב-Excel השורה הראשונה היא כותרות.
5. בכרטיסייה **שלבי עבודה** ערוך, הוסף וסדר את פעולות האתר.
6. בכרטיסייה **הפעלה** התחל ב"מצב בדיקה בלבד".
7. לאחר אימות השלבים, בטל מצב בדיקה והרץ בדפדפן. מנוע Python יתחבר לחלון Chrome של המערכת. שלב ידני יעצור את המנוע עד ללחיצה על "המשך אחרי פעולה ידנית".

## עמודות מומלצות בקובץ הנתונים

`שם לקוח`, `תז`, `גוש`, `חלקה`, `מגרש`, `יישוב`, `מספר תכנית`, `שם תכנית`.

בתוך שלב ניתן להפנות לעמודות באמצעות משתנים כמו `{client_name}`, `{id_number}`, `{block}`, `{parcel}` ו-`{username}`.

## סוגי השלבים

- `goto` – פתיחת כתובת.
- `click_text` – לחיצה לפי טקסט נראה.
- `click_role` – לחיצה לפי תפקיד נגישות ושם.
- `fill_label` / `fill_placeholder` – מילוי שדה מהטבלה.
- `fill_secret` – מילוי הסיסמה מהאחסון המאובטח.
- `wait_url` / `wait_text` – המתנה למסך הבא.
- `manual` – עצירה לפעולת משתמש.
- `screenshot`, `delay`, `noop` – צילום, השהיה או שלב תיעוד.

השלבים האוטומטיים של הזדהות באמצעות סיסמה קיימים בתבנית אך כבויים עד שנאמת יחד את שמות השדות המדויקים באתר.

## הקלטת לחיצות

בכרטיסייה **שלבי עבודה** לחץ **התחל הקלטת פעולות** והמתן לחיווי האדום **מקליט עכשיו**. בצע את ההדגמה ב-Chrome ולאחר מכן לחץ **עצור הקלטה**. המערכת קולטת פעולות גם במסגרות פנימיות של אתר מבא״ת. ערכים שהוקלדו אינם נשמרים; סיסמה מזוהה כשלב `fill_secret` ללא ערך גלוי.

אפשר לבחור כמה פעולות בעזרת `Ctrl` או `Shift`, למחוק או להשהות אותן יחד, להזיז אותן למעלה/למטה ולהוסיף פעולה לפני או אחרי הבחירה. מקש `Delete` מוחק את הבחירה ומקש רווח מפעיל/משהה אותה.
